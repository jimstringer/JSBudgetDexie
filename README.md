# React + TypeScript + Vite + Dexie

A personal Expense/Income Tracking app using Dexie to store data local in IndexedDB.
This will replace jsbudget2023 that uses firestore.

Must run on my iPhone so expenses can be entered easily. Most times you get a receipt
but sometimes at fast food or coffee shops its easier to enter right away rather than
ask for receipt.

Will use one of these to export-import to/from my home computer.

- $ npm install indexeddb-export-import
- $ npm install dexie-export-import
